농약 추천 안내

농약은 등록·취소·사용기준이 바뀔 수 있습니다. 특정 제품을 확정 처방하지 않고, 고추에 등록된 약제를 고르는 기준과 성분군 예시를 제공합니다. 실제 살포 전 제품 라벨, 작물명 ‘고추’, 대상 병해충, 희석배수, 수확 전 사용 가능일수, 사용 횟수, PLS 기준을 확인하세요.

농약 구매 전 6단계 확인

  1. 작물명에 고추가 적혀 있는지 확인
  2. 대상 병해충명이 맞는지 확인
  3. 희석배수와 살포량 확인
  4. 수확 전 사용 가능일수 확인
  5. 연간 사용 횟수 제한 확인
  6. 직전 사용 약제와 다른 작용기작인지 확인
