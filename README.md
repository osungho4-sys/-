# Original Mini Football (React + TypeScript + Vite)

## 실행 방법
```bash
npm install
npm run dev
```

## 새로 추가된 업그레이드
- 선수 선택 화면 (Sprinter / Playmaker / Striker)
- 능력치 시스템 (속도, 슛 파워, 패스 정확도)
- 난이도 선택 (Easy / Normal / Hard)
- 경기 시작 3,2,1 카운트다운
- 미니맵
- 공 소유 선수 아이콘
- 골 세리머니 연출
- 모바일 조작 버튼 크기/위치 개선
